The keys shown are your current ones. Change them in Settings › Controls. Controllers are mapped by button position, as on the console, whatever their labels say.

This cartridge has a rumble motor. A controller that supports haptics rumbles with it.

This cartridge has a tilt or motion sensor. Tilt the console with a controller's right stick.

This cartridge has a solar sensor. Set the amount of sunlight in Emulation › Solar Sensor: ⌘[ darker, ⌘] brighter.

The window

  • Title bar: the picture fills the window. The title and window buttons appear when the mouse is at the top of the window and hide again two seconds later. Drag the picture to move the window.
  • Borderless (⌘B): no title bar or border, and the window stays above other windows. Drag the picture to move it.
  • Full screen (⌃⌘F): the picture is letterboxed in black and the pointer hides until you move the mouse. Press Esc to leave. Full screen turns borderless off.
  • Size: View › Frame Size sets the picture to 1×–6× the console's screen (⌘1–⌘6); Actual Size (⌃⌘A) is 1×. With Lock Aspect Ratio (⌘A) on, resizing keeps the screen's shape.
  • Display sleep: the display stays awake while the game runs and isn't paused, since a controller doesn't count as activity. Turn this off in Settings › General.

The window's size, position and borderless setting are remembered.

Settings

Settings (⌘,) belong to this game only. They are mGBA's own settings, keeping what applies to it.

General

  • Folders: where battery saves, save states and screenshots go. Choosing a new save folder copies the save there (unless one is already there, which is then used). Default goes back to the game's own folder.
  • Pause when the app is in the background.
  • Keep the display awake while playing.

Audio/Video

  • Volume and Mute.
  • Clean up GBA music: GBA games mix their music at a low rate of their own, and the console plays it without smoothing, which adds a harsh hiss above the music. Small speakers can't reproduce it; studio monitors and headphones do. This filters it out, following the game's rate. On by default.
  • Lock aspect ratio, Borderless window, Force integer scaling, Interframe blending, Bilinear filtering: as in the View menu.

Emulation

  • Show the BIOS boot animation: the Game Boy AdvanceGame Boy start-up logo.
  • Fast-forward speed: 2×–8×, or unbounded (as fast as the Mac can go).
  • Idle loops: how mGBA skips a game's busy waiting, to save power. "Detect and remove" suits nearly every game; "Run all" is the most exact.
  • Allow opposing directions: left and right (or up and down) at once, which some games mishandle.
  • Rewind: on or off, how many states it keeps (600 by default, about ten seconds) and how often it records one.

Game Boy

  • Model: which console runs the game: autodetect, Game Boy, Super Game Boy, Game Boy Color or Game Boy Advance. Some games behave differently on each; Super Game Boy games show their border and colours.
  • Super Game Boy borders.
  • Colorization: colours for original Game Boy games, from the Game Boy Color's or the Super Game Boy's built-in palettes.
  • Palette: a preset palette for black-and-white games.

Game Boy Advance

  • Game Boy Player features: rumble in the games that supported the GameCube's Game Boy Player.
  • Solar sensor: the amount of sunlight, as in the Emulation menu.

Controls

Click a button's key, then press the new key. Restore Defaults brings back the standard keys. Game controllers need no setup.

Saves and states

  • Battery save: the game's own save, as on the cartridge. It is written while you play and when you quit, and it uses mGBA's file name, so a save from mGBA can be imported (File › Import Battery Save) or copied in.
  • Save states freeze the whole console at one moment, in nine slots or in files, in mGBA's format. Loading a state doesn't change the battery save; the game writes that again the next time it saves.
  • Rewind: hold ` (or the left trigger) to go back in time.

Tips

  • If the game looks too small or too big, use ⌘1–⌘6, or full screen.
  • If the picture flickers, try View › Interframe Blending.
  • Controllers can be connected or switched on at any time while the game runs.
  • This cartridge has a clock. It follows your Mac's clock.
